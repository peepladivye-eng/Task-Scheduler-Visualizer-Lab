# Plan 01-01: Event Sink Architecture & Strace Audit

## Context
In live mode, the engine must emit events synchronously as POSIX syscalls return rather than fabricating logs afterwards. This plan establishes the formal event model `LiveEvent`, the `IEventSink` abstraction, the three target sinks (`TraceCollectorSink`, `NdjsonSink`, and `TerminalSink`), and the baseline strace audit.

   - `t=  0 RUN      P1 os_pid 8571 tick 1/5`
