# Plan 01-02: Wire Real-Time Syscall Event Emission into Execution Controller & Backends

## Context
Now that `IEventSink` and its concrete sinks exist, this plan wires event emission into the heart of the execution loop in `engine-cpp`. It transitions from lazy forking to real arrival-time forking, instruments real syscall returns, and ensures synchronous event delivery across both signal and pipe backends.

## Tasks

<task id="01-02-T1">
<description>
Update `simulate_with_workers` in `execution_controller.cpp` to perform arrival-time forking and coordinate with `IEventSink`.
</description>
<files>
engine-cpp/include/scheduler/execution_controller.hpp
engine-cpp/src/scheduler/execution_controller.cpp
</files>
<action>
1. Replace lazy forking (`if (!forked[pid])`) with arrival-time forking:
   - At each virtual tick `t`, check for any process whose `arrival == t`.
   - Call `backend->spawn(pid, burst)`.
   - As soon as child's initial `SIGSTOP` is confirmed by `wait4`, emit `ARRIVE` event to `IEventSink`:
     `LiveEvent{ LiveEventType::ARRIVE, t, pid, os_pid, ... }`.
   - Add arriving processes to the ready queue snapshot.
2. On process dispatch:
   - Emit `DISPATCH` event with current ready queue snapshot:
     `LiveEvent{ LiveEventType::DISPATCH, t, pid, os_pid, ready_queue, ... }`.
3. On tick run:
   - Emit `RUN` event showing logical PID, OS PID, and current/total burst tick:
     `LiveEvent{ LiveEventType::RUN, t, pid, os_pid, tick, burst, ... }`.
4. On preemption:
   - When a tick completes and the process is preempted (quantum expired or higher priority process ready), emit `PREEMPT` event:
     `LiveEvent{ LiveEventType::PREEMPT, t, pid, os_pid, reason, ready_queue, ... }`.
5. On completion:
   - When child process exits and `wait4` reaps it, collect `WorkerStats` (`cpu_ms`, `max_rss_kb`, `exit_status`).
   - Emit `EXIT` event:
     `LiveEvent{ LiveEventType::EXIT, t, pid, os_pid, cpu_ms, max_rss_kb, ... }`.
6. On cleanup:
   - In `abort_all()` / exit path, emit `CLEANUP` event:
     `LiveEvent{ LiveEventType::CLEANUP, t, live_count, reaped_count, zombies, pgid, ... }`.
</action>
<verify>
Engine compiles with no warnings; running `scheduler_cpp --mode live --log` shows arrival forks at `t=0` for all tasks arriving at 0.
</verify>
</task>
