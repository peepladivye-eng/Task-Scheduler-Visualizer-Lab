# Plan 02-01: Header, Formatting, Color & Live Gantt Renderer

## Context
Phase 2 turns `TerminalSink` into an interactive terminal interface for WSL2. This plan implements the header, TTY and `NO_COLOR` detection, color coding per PID, and flicker-free live in-place Gantt rendering.

## Tasks

<task id="02-01-T1">
<description>
Add TTY detection, `NO_COLOR` checking, and ANSI color palette helpers to `TerminalSink`.
</description>
<files>
engine-cpp/include/common/event_sink.hpp
engine-cpp/src/trace/event_sink.cpp
</files>
<action>
1. Detect whether `out_` is a TTY using `::isatty(::fileno(out_))`.
2. Check `std::getenv("NO_COLOR") != nullptr`.
3. Provide ANSI color helper returning color escape codes for PID 1..N when `is_tty && !no_color`, and empty strings otherwise.
4. Support reset escape code `\033[0m`.
</action>
<verify>
Running with `NO_COLOR=1` strips all ANSI color codes; running on TTY emits colors.
</verify>
</task>

<task id="02-01-T2">
<description>
Print execution header at the start of live mode showing Parent PID, PGID, Algorithm, and IPC backend.
</description>
<files>
engine-cpp/src/trace/event_sink.cpp
engine-cpp/src/scheduler/execution_controller.cpp
</files>
<action>
1. Implement `print_header(...)` in `TerminalSink` displaying:
   - Boxed title: `CPU SCHEDULER — REAL PROCESS EXECUTION (WSL2)`
   - Parent PID (`getpid()`), PGID (`backend->pgid()`)
   - Algorithm, quantum, CS cost
   - IPC backend (signal or pipe)
2. Trigger header printing before the virtual tick loop begins.
</action>
<verify>
Header appears before the first `ARRIVE` line in `scheduler_cpp --mode live --log`.
</verify>
</task>

<task id="02-01-T3">
<description>
Implement in-place live Gantt drawing on TTY mode without flicker using ANSI cursor controls.
</description>
<files>
engine-cpp/src/trace/event_sink.cpp
</files>
<action>
1. For TTY output, maintain an in-memory tick timeline buffer in `TerminalSink`.
2. After each event or tick update, if on TTY:
   - If previous Gantt block was rendered, emit `\033[<H>A` to move cursor up.
   - Redraw the Gantt lines for each active process up to current virtual tick `t`.
3. For non-TTY output (pipes, files, CI), bypass ANSI cursor positioning and emit plain sequential lines.
</action>
<verify>
Live Gantt draws cleanly during execution without duplicate blocks or screen tearing.
</verify>
</task>

## Verification
1. `bin/scheduler_cpp --algo fcfs --input fixtures/fcfs_textbook/input.txt --mode live --ipc signal --log` displays header and formatted event lines.
2. `NO_COLOR=1 bin/scheduler_cpp ...` produces plain monochromatic output.
3. Pipe output (`... | cat`) contains plain lines with no cursor escape sequences.
